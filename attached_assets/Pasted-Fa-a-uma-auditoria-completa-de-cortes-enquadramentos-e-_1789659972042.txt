CAUSA TÉCNICA

Verifique em cada ícone:

- `overflow: hidden`;
- largura ou altura insuficiente;
- `line-height` inadequado;
- `padding` insuficiente;
- margem negativa;
- `transform: scale()` ou `translate()` excessivo;
- `flex-shrink`;
- SVG com `viewBox` incorreto;
- SVG sem largura e altura definidas;
- imagem usando `object-fit: cover`;
- elemento posicionado fora do contêiner;
- recorte causado pelo raio de borda;
- contêiner herdando altura menor que o conteúdo.

Não esconda o problema reduzindo excessivamente os ícones.

PADRÃO DOS ÍCONES

Crie um componente visual compartilhado para os ícones:

- contêiner quadrado;
- largura e altura consistentes;
- alinhamento com `display: flex`;
- `align-items: center`;
- `justify-content: center`;
- `flex-shrink: 0`;
- `box-sizing: border-box`;
- espaço interno suficiente;
- ícone completamente visível;
- proporção preservada.

Para SVGs:

- use um `viewBox` que contenha todo o desenho;
- defina `width` e `height`;
- use `display: block`;
- preserve a proporção;
- evite traços encostados nas extremidades do `viewBox`;
- use `overflow: visible` quando o desenho possuir traços externos;
- não corte sombras, contornos ou detalhes.

Para PNG ou WebP:

- use `object-fit: contain`;
- use `object-position: center`;
- não use `cover`;
- mantenha fundo transparente;
- não estique a imagem.
